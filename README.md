# Mango-Strike
Mango-Strike — простой 2D-шутер с улучшениями оружия и способностями, дающимися с каждым уровнем. Управляйте боевым дроном, отражайте волны ботов (снайперов, танков, разведчиков) и открывайте мощные синергии (орбитальный спутник, рикошеты). Игра написана на чистом JS в одном HTML-файле с Web Audio API и системой рекордов.
