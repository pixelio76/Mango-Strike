# Mango-Strike 🚀

Mango-Strike — простой 2D-шутер с улучшениями оружия и способностями, дающимися с каждым уровнем. Это динамичная аркадная веб-игра, написанная на чистом JavaScript с использованием HTML5 Canvas, в которой вам предстоит управлять боевым дроном и сдерживать натиск бесконечных волн разнообразных роботов-захватчиков.

Проект разработан в рамках концепции Single-File Architecture (все ресурсы, стили, логика и звуки упакованы в один компактный HTML-файл), что делает его идеальным для мгновенного запуска

✨ Ключевые особенности

🛡️ Уникальная система прогрессии и синергии

С каждым новым уровнем вам предлагается на выбор протокол модернизации боевого костюма. Вы можете комбинировать пассивные улучшения и уникальные модули, создавая разрушительные сборки:

Сплит-лазер (x3): выпускает три снаряда веером.

Осколочные и Разрывные снаряды: устраивают цепные взрывы и разлетаются на мелкие смертоносные осколки при попадании.

Самонаводящиеся пули и Модуль рикошета: позволяют снарядам автоматически доворачивать во врагов и отскакивать от стен арены.

🛸 Орбитальный Спутник: уникальный защитный дрон, который непрерывно вращается вокруг вас и наносит урон всем соприкасающимся врагам.

🤖 Разнообразие противников

Каждая волна усложняет выживание, выводя на арену новые типы умных ботов:

Разведчик (SCOUT): быстрый маневренный бот. Каждые несколько мгновений задействует маскировку (становится полупрозрачным), снижая получаемый урон на $50\%$.

Снайпер (SNIPER): держится на дистанции и раз в $1$ секунду производит точечный выстрел, наносящий фиксированные $20$ единиц урона.

Тяжёлый Танк (TANK): медленный бронированный исполин с колоссальным запасом прочности в $3000$ ХП.

Дроны-камикадзе, Элитные охотники, Исполины и Боссы (появляются на каждой 5-й волне).

💔 Хардкорные тактические механики

Динамическая виньетка: чем меньше уровень прочности вашего дрона ($HP$), тем сильнее сжимаются темные и багровые границы экрана, уменьшая ваш тактический угол обзора.

Штраф к перезарядке: при критическом уровне здоровья скорость стрельбы вашего орудия может снизиться до $2.5$ раз.

Кулдаун коллизий: устранен баг мгновенной смерти в толпе — враги наносят урон при прикосновении строго раз в $0.5$ секунды.

Сбалансированная прокачка: начиная с $\ge 20$ уровня, каждый собранный кристалл опыта дает гарантированный минимум в $1\%$ от требуемого значения для левелапа, предотвращая «застревание» прогресса.

🔊 Синтезатор звука и система рекордов

Вся аудиосистема построена на динамическом синтезе частот через Web Audio API (без использования внешних тяжелых звуковых файлов).

Интегрировано сохранение рекордов в локальное хранилище браузера (localStorage) — боритесь за лучший результат, который сохранится даже после закрытия вкладки!

🛠️ Технологический стек

Язык: JavaScript (ES6+)

Рендеринг: HTML5 Canvas API (высокая производительность и пиксельный стиль)

Стили: Tailwind CSS

Иконки: Lucide Icons (динамический рендеринг через CDN)

Звуковое сопровождение: Web Audio API (генеративный синтез звуков выстрелов, взрывов и левелапов)

🎮 Как играть

Запуск проекта

Просто скачайте файл index.html и откройте его в любом современном браузере. Установка дополнительных зависимостей или серверов не требуется!

Управление

W, A, S, D — Маневрирование дроном.

Мышь — Направление прицеливания.

Левая кнопка мыши (ЛКМ) — Стрельба.

Esc / P — Пауза боевой симуляции.
